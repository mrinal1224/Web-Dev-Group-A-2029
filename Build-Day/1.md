# ✅ **1. Simple Soundboard (Audio API)**

### ⭐ Web API: `new Audio()`

## 📌 Idea

A basic soundboard where each button plays a sound. That’s it.
Very small, very fun.

## 🎯 Features

* 4–6 buttons (Dog, Clap, Pop, Laugh)
* Clicking plays the sound
* One volume slider
* (Optional) Mute button

## 🧩 What students learn

* Audio API basics
* Simple button event listeners
* DOM structure (grid)

# ✅ **2. Copy-Paste Helper (Clipboard API)**

### ⭐ Web API: `navigator.clipboard`

## 📌 Idea

A textarea with two buttons: **Copy** and **Paste**.

## 🎯 Features

* “Copy Text” → copies textarea text
* “Paste Text” → pastes clipboard content into textarea
* A small status message: “Copied!”

## 🧩 What students learn

* Clipboard API
* Working with textarea value
* Basic error handling (in case browser blocks paste)

# ✅ **3. Mini Quote Saver (localStorage)**

### ⭐ Web API: `localStorage`

## 📌 Idea

A super simple quote saver.

## 🎯 Features

* Input field → Add Quote button
* Show all saved quotes as list items
* Delete a quote
* All quotes stay saved on refresh

## 🧩 What students learn

* Rendering a list dynamically
* Simple CRUD operations

# ✅ **7. Easy Countdown Timer with Alert (Notification + Audio)**

### ⭐ Web API: Notification + Audio

(Still simple. Two easy APIs.)

## 📌 Idea

Enter seconds → countdown → show notification + beep sound.

## 🎯 Features

* Input seconds
* Start button
* Live countdown display
* At zero:

  * Notification “Timer finished!”
  * Play alert sound

## 🧩 What students learn

* setInterval basic
* Notification simple usage
* Audio feedback
